## O que foi feito nesta resposta

### 1. Correção dos 5 testes quebrando após o refactor P0
Os testes `test_inference_t_test`, `test_inference_chi_square`, `test_inference_anova_and_levene`,
`test_inference_skips_duplicates` e `test_demo_pipeline_end_to_end` falhavam por diferenças
entre o refactor e a suíte antiga. Foram reconciliados:
- `InferenceEngine` ganhou *wrappers* de delegação para `run_t_test/run_chi_square/run_anova`
  (a matemática vive em `app.core.statistics`; a API pública histórica permanece estável).
- `run_all_inference` passa `group_b=None` para o t-test (semântica "Outros"), ver abaixo.
- `test_inference_skips_duplicates` agora localiza o t-test por `test_type == 'welch_t'`.
- Regex de parsing da média ajustado para o texto com aspas (`'Aprovado' (Média=...)`).

### 2. Três bugs REAIS encontrados e corrigidos (não só ajuste de teste)
| Bug | Onde | Sintoma | Correção |
|-----|------|---------|----------|
| Unpacking errado do `multipletests` | `app/core/statistics.py` | `TypeError: 'float' object is not iterable` ao aplicar correção de Bonferroni no `/api/demo` | `statsmodels.multipletests` retorna `(reject, pvals_corrected, alphacSidak, alphacBonf)`; ajustado para `rejected, pvals_adj, _, _ = ...` |
| Conflito de kwargs no schema | `app/api/routes.py` | `TypeError: got multiple values for keyword argument 'p_value_adjusted'` | chaves duplicadas excluídas de `**r` antes de construir `InferenceResult` |
| *Shadowing* de módulo `warnings` | `app/core/statistics.py` (`run_t_test`) | `UnboundLocalError` silenciosamente engolido → t-test retornava `None` | variável local renomeada para `warn_msgs` |

### 3. Robustez estatística e de tipos
- **Semântica "Outros":** `run_t_test(df, num, grp, "Aprovado")` agora compara contra
  *todas as linhas que não são "Aprovado"*, corrigindo o bug histórico onde o rótulo
  literal `"Outros"` nunca casava e o grupo de comparação ficava vazio.
- **Grupos degenerados (variância zero):** retornam `None` graciosamente em vez de
  produzir `inf/nan`.
- **Profiler:** `infer_type` classifica colunas booleanas como `"boolean"` (antes eram
  rotuladas como `"number"` e quebravam no quantile); `detect_outliers` protege contra
  dtype booleano.

### 4. 23 novos testes de caracterização (prova do valor do projeto)
- `tests/test_statistics.py`: tamanhos de efeito (Cramér's V, Cohen's d, eta²); Levene
  aceita/rejeita; troca clássico→Welch na ANOVA; Bonferroni (raw vs ajustado + decisão
  de rejeição); avisos de Cochran no qui-quadrado; casos de borda do t-test.
- `tests/test_scoring.py`: pesos somam 1; denominador exclui `is_duplicate` (bug histórico
  corrigido); outlier = anomalia de plausibilidade com penalidade 0.0; monotonicidade;
  reconstrução do score; intervalo [0,100]; versionamento exposto.
